# Simplified Biáng display outline

The compact choice-button and header glyph in `src/games/chineseHandwritingBiangGlyph.ts` uses the simplified **𰻝 (U+30EDD)** outline from [File:Biang (简体).svg](https://commons.wikimedia.org/wiki/File:Biang_(%E7%AE%80%E4%BD%93).svg), by **LiliCharlie and Cangjie6**. The Commons description identifies this as the simplified character for biángbiáng noodles. The current vector revision was uploaded on 14 March 2020.

- Original SVG SHA-256: `37b44803a0081256148e4c8c27f7e618c4f6abf01dee40ce55fbf16bb06b514c`.
- Normalized path-data SHA-256: `596d9fe4249272910cbca0635bb5b9a0ff70c02799479272e976e0da0ea94a72`.

FoldKid's 2026-11-18 adaptation removes editor metadata and normalizes whitespace, retaining the original single filled path and `106 -106 512 512` view box. It sets the fill to `currentColor` and embeds the path directly into the app's SVG markup. These adaptations to the outline are distributed under the same CC BY-SA 4.0 license. The authors do not endorse FoldKid.

The glyph requires no font, `<img>`, SVG-image fetch, PNG, JPEG, or other runtime resource. The outline is for crisp display at small sizes; the separate ordered tracing guide in `chineseHandwritingBiang.ts` remains based on the Arphic-licensed component medians documented in [BIANG.md](BIANG.md). Its stroke count, pen directions and tracing points do not come from this filled outline.
