# Bundled fonts

Downloaded from the official Google Fonts CSS API and fonts.gstatic.com on 2026-11-02. These WOFF2 files are unmodified.

- Comic Neue: regular (400) and bold (700), Latin subset. Other requested weights use the same nearest-weight matching as the previous hosted font. [Family source](https://github.com/google/fonts/tree/main/ofl/comicneue), [SIL Open Font License](comicneue-OFL.txt).
- Rubik: normal variable weights 400–900, Arabic and Latin subsets. Arabic includes the Persian glyphs used by the Farsi UI. [Family source](https://github.com/google/fonts/tree/main/ofl/rubik), [SIL Open Font License](rubik-OFL.txt).

Chinese and Japanese continue to use platform fallback fonts. Only the scripts and normal styles used by the app are bundled.
