# New Game Ideas

Timestamp: 2026-06-19 11:36 Europe/London

These ideas fit the existing Foldkid architecture: Foldkit model/message/update/view modules, Effect-backed commands, child-friendly audio/speech, i18n, and focused game tests.

## Strong Fits

1. Shape Sorter

   Drag shapes into matching baskets by color, size, or shape.

   This would reuse Find It-style drag/drop and Bubbles-style color play.

2. Sound Match

   Play a sound, then pick the matching object, animal, or instrument.

   This would extend `audio.ts`, `speech.ts`, and Music Box audio ideas.

3. Memory Cards

   Flip cards and match emoji, numbers, letters, or sounds.

   The model would be clean: deck, flipped cards, matched ids, attempts, and win state.

4. Letter Garden

   Letters fall, grow, or appear like flowers; tap the spoken target letter.

   This would reuse speech prompts, Draw's letter domain, and a simple animation loop.

5. Rhythm Tap

   A beat plays and the child taps along. Score based on timing windows.

   This would be a natural Music Box spin-off with simpler playback rules.

6. Color Mixer

   Combine two colors to make a target color, such as red plus yellow becoming orange.

   This would pair nicely with Bubbles' palette and visual feedback.

7. Number Train

   Build a train by ordering numbered cars: 1, 2, 3, and so on.

   This would reuse drag reorder logic like the landing page, Music Box song list, and Find It collection.

8. Tiny Maze

   Move a character through a grid to collect a target emoji, number, or letter.

   This could be mostly pure reducer logic with keyboard and touch controls.

9. Pattern Builder

   Show a sequence such as red-blue-red-blue, then ask the child to complete it.

   This would be very testable: deterministic pattern generation, mistake feedback, and next-round behavior.

10. Animal Orchestra

   Tap animals to layer sounds; each animal controls a loop, note, or simple rhythm.

   This would build on Music Box but feel more playful and less complex.

## Best Next Candidates

- Memory Cards: very testable, contained, and useful as a clean new game module.
- Shape Sorter: visually rich without complex audio or machine learning.
- Rhythm Tap: distinctive, and it would reuse the Music Box/audio work.
- Letter Garden: fits the existing Draw and Find It learning theme.

Recommended first pick: Memory Cards. It would add a classic child-friendly game with low architectural risk, strong test coverage, and room for modes such as emoji, numbers, letters, sounds, or mixed pairs.
